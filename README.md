# 快速梳理（onboard）

把一大堆项目材料扔给 AI：它先识别项目类型、拆解项目怎么运转，再排一条跟你的目标
挂钩的学习路径，然后默认带你学。代码仓库、业务流程、制度文档堆都适用。

## 用法

```bash
git clone https://github.com/Keviniscool-boy/onboard ~/.agents/skills/onboard
```

然后对 agent 说：

> 资料都在 `D:\new-project`，我是后端新人，两周内要能改支付模块，开始带我上手。

你会得到一个 `项目拆解包/`：

- **总览**（两页内）：这是什么类型的项目、怎么运转、上手关键点、哪些材料查了
  哪些没读——每条结论挂出处，推出来的标推断，缺的列成待确认问题。
- **学习路径**：三档——现在要懂 / 遇到时查 / 暂时可略过。重要不重要跟你的目标
  走，不由材料篇幅决定；每个「现在要懂」项附一个上手动作。

拆解完默认开始带学，每个部分用一个简短问题确认理解；你说「只要拆解」就到此为止。

## 这个 skill 的立场

- **拆解优先于教学**：先产出可核查的项目认知，讲解只是消化它的手段；带学中发现
  遗漏，回补进拆解包，不在对话里现编。
- **重要性跟目标走**：影响你理解项目、完成任务、避免错误的内容才是重点；细节不
  求面面俱到，用三档控制阅读量。
- **不知道就标出来**：材料明说的挂出处，推出来的标待验证，缺的列成待确认——
  重要但材料里没有的，本身就是最重要的问题。
- **跨行业靠方法不靠装懂**：先识别类型（代码系统 / 公司业务 / 流程制度 / 文档堆 /
  数据报表 / 混合）再选拆解维度，材料撑不出的结论就说撑不出。
- **默认只读、产物精简**：不改源文件、不跑有副作用的操作、密钥默认不碰、材料不
  出本地；必产只有总览和路径两份，其余按需。
