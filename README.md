# 快速梳理（onboard）

把公司资料扔给 AI，它直接开课带你学——不生成文档堆。

## 用法

```bash
git clone https://github.com/Keviniscool-boy/onboard ~/.agents/skills/onboard
```

然后对 agent 说：

> 资料都在 `D:\new-company`，我是后端新人，两周内要能改支付模块，开始带我学。

你会得到一场教学，不是一堆文件：2 分钟扫完资料 → 3 分钟讲清这门生意怎么赚钱、
你站在哪、课程表几站 → 逐站带学，每站讲完考你一句，答错换个讲法重讲 →
结课你复述全景，它交你一份"该问导师的问题清单"。
学到哪了记在一张进度卡里，下次会话接着学。

## 和"生成 wiki 的工具"的区别

不产出没人看的文档。学习过程是产品：互动、每站有考题、重要结论挂出处，
推不出来就直说"材料里看不到"。

## 状态

代码向（接手大型仓库）与纯文档向（一份无结构内训文字稿 + 助教角色）均已用
"陌生 agent + 真实资料"实测通过：3 分钟内开课，除一张进度卡外零落盘，
教学循环（考-判-换讲法）完整跑通。

**适用边界（如实）**：行业不限——核心循环只依赖"只从材料学"。但 PDF/PPT/Excel
等格式还没实测过；资料极少的场景它教不了，只能生成问导师清单。声明只到实测为止。
